# Authenticated Access Token Factory Example - Frontend

This is the frontend example application demonstrating authenticated access token factory for real-time communication using SignalR.

## Prerequisites

- Node.js (version 16 or higher)
- npm or yarn

## Installation

1. Clone the repository or navigate to the frontend directory.
2. Install dependencies:

```bash
npm install
```

## Running the Application

To start the development server:

```bash
npm run dev
```

The application will be available at `http://localhost:5173` (default Vite port).

## Building for Production

To build the application for production:

```bash
npm run build
```

The built files will be in the `dist` directory.

## Preview Production Build

To preview the production build locally:

```bash
npm run preview
```

## Technologies Used

- React 18
- TypeScript
- Vite
- SignalR (@microsoft/signalr)
